FTP — TCP 20 / 21

FTP is a generic file transfer protocol. TCP port 20 is often used for active data transfer, while TCP port 21 is often used for administration or control. FTP can authenticate users and can also be configured for anonymous access.

SSH vs. Telnet

SSH provides an encrypted communication link over TCP port 22. Telnet commonly uses TCP port 23 and sends communication in clear text. The source describes SSH as the preferred secure approach, while Telnet may remain on older systems that do not support SSH.

DNS — UDP 53

The Domain Name System translates a fully qualified domain name into a usable IP address for network communication. DNS is important because people commonly remember names rather than numeric IP addresses. Multiple DNS servers can provide redundancy.

Page 6 • Automatic Configuration
DHCP — UDP 67 / 68

DHCP automatically provides IP configuration parameters. A DHCP service maintains a pool of addresses; a device receives an address for a lease period and may renew it. Administrators can reserve an address so a printer or server receives the same address each time.

POP3 vs. IMAP4

POP3 commonly uses TCP port 110 to transfer email down to a computer. IMAP4 commonly uses TCP port 143 and provides additional mailbox-management features, including folders and synchronization across multiple email clients.

TCP 110 • POP3TCP 143 • IMAPMulti-client sync

Page 9 • Windows Networking
SMB / NetBIOS

SMB, also called CIFS, is used by Windows for file transfers, printer queues, and other communication. Older Windows systems used NetBIOS: UDP 137 for name service and TCP 139 for sessions. Modern Windows commonly uses direct IP connectivity without NetBIOS and often uses TCP 445.

UDP 137 • NameTCP 139 • SessionTCP 445 • Direct SMB

LDAP / LDAPS

LDAP is the Lightweight Directory Access Protocol and commonly uses TCP port 389. The source describes directory information organized into categories such as an organization, organizational unit, and common name. LDAP is commonly used with Microsoft Active Directory.

Page 11 • Remote Access & Review
RDP — TCP 3389

Remote Desktop Protocol allows a user to view and control a remote computer across the network. It is primarily associated with Windows devices, and clients exist for other operating systems. It can control an entire computer or run a single remote application.
